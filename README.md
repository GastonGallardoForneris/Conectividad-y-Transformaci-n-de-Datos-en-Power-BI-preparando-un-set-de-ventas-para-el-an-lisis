# Limpieza de ventas con Power BI

Práctica del módulo 6 del curso de Data Analytics de Coderhouse.

Autor: Gastón Gallardo Forneris.

## Objetivo

Preparar un archivo de ventas mediante Power Query:
corregir nombres y tipos de datos, tratar duplicados y valores
faltantes, y separar clientes de transacciones.

## Archivos

- Documentacion_Modulo6_Gaston_Gallardo.pdf:
  documentación de las transformaciones, decisiones y capturas.
- Practica_Modulo6.pbix:
  proyecto de Power BI.
- Ventas_export_legacy.xlsx:
  archivo original del ejercicio.

## Resultados

- 899 ventas preparadas para el análisis.
- 119 clientes con identificadores únicos.
- 1 operación conservada en una consulta de revisión por falta
  de total y descuento: OP-100080.

## Abrir el proyecto

Abrir el archivo PBIX con Power BI Desktop.

Para actualizar los datos en otra computadora, ajustar la ruta
del Excel en el paso Origen de las consultas que apuntan al archivo.
La consulta de revisión también puede conservar la ruta original.
